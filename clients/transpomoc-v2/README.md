# TransPomoc — wersja koncepcyjna v2

Projekt nieoficjalny z sześcioma stronami: start, pomoc drogowa, wynajem, transport, galeria, kontakt. Oryginalne repozytorium Portfolio nie było modyfikowane.

Zawiera informacje o usługach i publiczny cennik wynajmu z https://transpomoc.com.pl/wypozyczalnia-lawet-poznan/ (do ponownej weryfikacji).

Zdjęcia są zastępcze (Unsplash). Finalnie należy zastąpić je zdjęciami realizacji właściciela po potwierdzeniu zakresu praw i otrzymaniu materiałów. Strona nie jest jeszcze oficjalną witryną firmy.
